## Descripción del Proyecto
Proyecto interactivo desarrollado en Unity utilizando Universal Render Pipeline (URP) y XR Interaction Toolkit (XRI). Incluye un entorno de entrenamiento delimitado, objetos manipulables mediante físicas y agarre (Grab), interacción a distancia mediante UI en espacio de mundo con raycast, y un área de teletransporte como mecánica de locomoción XR.

## Requerimientos Implementados
1. Configuración del proyecto XR con URP y XRI.
2. Escenario delimitado con piso, iluminación y objetos 3D.
3. Objetos interactuables con Rigidbody y XR Grab Interactable.
4. Interacción a distancia mediante Ray Interactor y botón UI en World Space.
5. Locomoción mediante Teleportation Area.

## Instrucciones y Controles
- Agarre directo de objetos con el botón Grip/Grab.
- Apuntar con el Ray Interactor y presionar Trigger para interactuar con la UI a distancia o teletransportarse en el área designada.
